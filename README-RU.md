# Ziyorat Tour — передача разработчикам

В архиве находится готовая статическая версия сайта для https://ziyorattour.uz.

## Быстрый запуск

Для размещения без изменения содержимого сборка не требуется. Содержимое папки `dist/`, включая скрытый файл `.htaccess`, нужно разместить в корне сайта либо настроить web root на эту папку. Не загружайте весь архив в публичный корень.

Перед заменой сохраните резервную копию действующего сайта и конфигурации хостинга.

Текущий старый сайт в Plesk использует Node.js. Необходимо настроить статическую раздачу новой папки или проксирование с эквивалентными правилами маршрутизации. Само копирование `.htaccess` не отключает существующее приложение.

## Состав

- `dist/` — готовые HTML, CSS, JavaScript, изображения, robots.txt, sitemap.xml, страница 404 и конфигурация Apache.
- `template.html` — редактируемый источник главной страницы и общих компонентов.
- `build.py` — генератор двух языковых версий и страниц уровней комфорта.
- `request.js` — логика составления запроса посетителя.
- `verify.py` — проверка страниц и ссылок.
- `requirements.txt` — зависимости для пересборки исходников.
- `SEO-STATUS.md` — выполненные SEO-настройки и проверки после публикации. Раздел о программах читать с учётом текущей модели индивидуального подбора: фиксированные отели и сроки убраны.

## Локальный просмотр

Из папки проекта:

    python3 -m http.server 4173 --directory dist

Откройте http://localhost:4173/ или http://localhost:4173/ru/.
Этот сервер не применяет `.htaccess` и предназначен только для просмотра.

## Пересборка после правок

Python 3.9+; рекомендуем отдельное виртуальное окружение:

    python3 -m venv .venv
    .venv/bin/pip install -r requirements.txt
    .venv/bin/python build.py
    .venv/bin/python verify.py

Правки вносить в `template.html`, `build.py`, `request.js`, затем пересобрать `dist/`. Правки только сгенерированных страниц будут перезаписаны.

## Адреса

- `/` — узбекская главная.
- `/ru/` — русская главная.
- `/uz/umra-standart/`, `/uz/umra-komfort/`, `/uz/umra-vip/`.
- `/ru/umra-standart/`, `/ru/umra-komfort/`, `/ru/umra-vip/`.
- `/#excursions`, `/ru/#excursions` — встроенный каталог экскурсионных маршрутов.
- `/#selection`, `/ru/#selection` — форма составления запроса.

На всех страницах canonical и hreflang настроены на https://ziyorattour.uz. Если домен меняется, изменить BASE в `build.py`, пересобрать и обновить доменные правила `.htaccess`.

## Сервер и SEO

Apache: использовать `dist/.htaccess`, разрешить необходимые override и модули rewrite/headers/deflate. Проверить совместимость директив с настройками хостинга.

Nginx или Node.js: реализовать эквивалентные настройки:

- HTTPS; единый домен ziyorattour.uz без www; перенаправления 301 с http/www.
- `/uz` и `/uz/` → `/` (301).
- `/blog-1/ru` → `/ru/umra-standart/`; `/blog-1/uz` → `/uz/umra-standart/`.
- Аналогично blog-2 → umra-komfort, blog-3 → umra-vip.
- Каталоги со статическим index.html должны открываться по своим адресам; не использовать SPA fallback для всех запросов.
- Для неизвестных адресов возвращать HTTP 404 и `404.html`, а не главную с кодом 200.
- Сжатие HTML/CSS/JS и кеширование ассетов с возможностью обновления при следующем релизе.
- Не блокировать роботов на уровне CDN/WAF, если сайт предназначен для индексации.

После размещения проверить HTTPS, коды 200/301/404, мобильную версию, обе языковые версии, JSON-LD и фактические адреса canonical. Отправить sitemap.xml в Google Search Console, Bing Webmaster Tools и Яндекс Вебмастер после подтверждения владения доменом.

## Важно: обращения посетителей (обновлено в октябре 2026)

Форма «Подобрать поездку» содержит поля «Имя» и «Телефон» и отправляет заявку на https://jubatravel.uz/lead.php,
который пересылает её в Telegram-группу Juba Bot с пометкой #ziyorattour. Посетитель видит «Заявка отправлена».
Если отправка не удалась, показывается подготовленный текст с кнопками «Скопировать» и «Открыть Telegram» (как раньше).
Список сайтов, которым разрешено отправлять заявки, — в lead.php (репозиторий jubatravel-site).

## Размещение на GitHub Pages

Сайт публикуется из папки dist/ workflow-ом .github/workflows/pages.yml (Settings → Pages → Source: GitHub Actions).
GitHub Pages не выполняет .htaccess: старые адреса /uz, /blog-1..3/ru|uz ведут на новые через небольшие страницы-перенаправления,
которые создаёт build.py; www и http перенаправляет сам GitHub Pages.

## Содержимое и права

Уровни Стандарт/Комфорт/VIP — ориентиры для индивидуального подбора. Стоимость, даты, отели и состав услуг подтверждаются с туроператором.
Три экскурсионных маршрута имеют краткое изложение этапов; порядок и наполнение согласуются перед бронированием. На сайте нет ссылок для бронирования у туроператора.

Фотографии Pexels сохранены локально, авторы и ссылки на источники указаны в `dist/photo-credits.html`; применять условия Pexels. Брендовые изображения извлечены из предоставленного заказчиком брендбука.
Gill Sans используется, если он установлен на устройстве; файлы коммерческого шрифта не приложены. Настроены запасные системные шрифты.

Перед запуском заказчику подтвердить актуальность контактов, официальных соцсетей и текстов. Юридические сведения, реальные отзывы, документы компании, политика обработки данных и аналитика не выдумывались и требуют отдельного согласования при добавлении.

## Проверки при передаче

Проверены 8 HTML-страниц, внутренние ссылки, якоря, ассеты, уникальные title, description, canonical, hreflang, JSON-LD и XML sitemap. Выполнена проверка синтаксиса JavaScript. Это не заменяет проверку сервера после публикации и не гарантирует позиции в поиске.
